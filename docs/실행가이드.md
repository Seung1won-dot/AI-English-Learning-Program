# English World 실행 가이드

[← README로 돌아가기](../README.md)

처음 실행하는 사람을 위해 한 단계씩 적었습니다. 컴퓨터를 잘 몰라도 따라 할 수 있어요.

---

## 0. 준비물 (한 번만)

- **Python 3.9 이상** (권장 3.11)
- 확인: 명령창(터미널)에서 아래를 입력해 버전이 보이면 됩니다.
  ```
  python --version
  ```
  macOS/Linux 는 `python3 --version`.

> "python을 찾을 수 없습니다"가 나오면 https://www.python.org 에서 설치하세요.
> Windows 설치 화면의 **"Add Python to PATH"** 체크박스를 꼭 켜세요.

---

## 1. Windows — 더블클릭으로 실행 (가장 쉬움)

프로젝트 폴더의 **`시작하기.bat`** 을 더블클릭합니다.

- 서버가 켜지고 2초 뒤 브라우저가 `http://127.0.0.1:5000` 으로 열립니다.
- 콘솔에 `폰에서 : http://192.168.x.x:5000` 이 보이면, 같은 와이파이의 폰에서도 그 주소로 접속할 수 있습니다.
  (처음 한 번 Windows 방화벽 "액세스 허용" 창이 뜨면 **허용**)
- `.venv` 가상환경이 있으면 그걸 쓰고, 없으면 시스템 Python 을 씁니다. 라이브러리가 없다면 아래 2단계를 먼저 하세요.

---

## 2. 터미널로 실행

프로젝트 폴더에서 명령창을 엽니다. (Windows: 탐색기 주소창에 `cmd` 입력 후 Enter)

**① 가상환경 만들기 + 라이브러리 설치 (최초 1회)**

Windows:
```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

macOS / Linux:
```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

**② 실행**
```
python app.py
```

콘솔에 `PC에서 : http://127.0.0.1:5000` 이 보이면 성공입니다. 브라우저에서 그 주소로 접속하세요.

다음부터는 가상환경 켜기(`activate`) → `python app.py` 만 하면 됩니다.

---

## 3. (선택) 실제 AI 켜기

이 단계는 **건너뛰어도 됩니다.** 키가 없으면 규칙기반 목업으로 모든 화면이 동작하고,
화면 위에 "목업 모드" 표시가 보입니다.

1. `.env.example` 을 복사해 `.env` 로 이름을 바꿉니다. (Windows: `copy .env.example .env`, macOS: `cp .env.example .env`)
2. `.env` 의 `GROQ_API_KEY=` 뒤에 무료 Groq 키를 붙여넣습니다. → [무료AI설정.md](무료AI설정.md)
3. 서버를 껐다 켜면 화면 위 표시가 "Groq (무료 AI) 연결됨"으로 바뀝니다.

## 4. 사용하기

- **홈** 에서 오늘 공부할 모드(단어 암기 / TOEIC / OPIC / 회화)를 고릅니다.
- **퀴즈** 에서 오늘 복습할 단어를 풀고, **기록** 에서 날짜별 학습과 통계를 봅니다.
- 오른쪽 위 버튼으로 밝은/어두운 화면을 바꿀 수 있습니다.

명령창에서 **`Ctrl + C`** 를 누르면 서버가 꺼집니다.

## 자주 묻는 문제

| 증상 | 해결 |
|------|------|
| `python` 을 찾을 수 없음 | Python 설치 + "Add to PATH" 체크 후 명령창 다시 열기 (macOS 는 `python3`) |
| `pip` 을 찾을 수 없음 | `python -m pip install -r requirements.txt` |
| 5000 포트가 이미 사용 중 | 다른 포트로 실행: Windows `set PORT=5001 && python app.py`, macOS `PORT=5001 python app.py` |
| 폰에서 접속이 안 됨 | `HOST=0.0.0.0` 으로 실행해야 합니다 (`시작하기.bat` 은 자동). PC와 폰이 같은 와이파이인지 확인 |
| 화면이 안 열림 | 명령창에 `PC에서 : http://...` 메시지가 떴는지 먼저 확인 |
| 개발 중 코드 수정이 바로 반영되면 좋겠음 | `FLASK_DEBUG=1` 로 실행 (내 PC 에서만, 공개 접속 시 자동으로 꺼짐) |

> 학습 기록은 폴더 안 `learning.db` 파일에 자동 저장됩니다. 이 파일을 지우면 기록이 초기화되니 주의하세요.
